# Research scripts

Analysis code from the sessions that decoded Plates 31–73. It covers fitting generators to the scans, overlays, self-avoidance and tiling checks, and Playwright checks of the pages. The scripts were written for one session's scratch folder, so their paths are stale and some read intermediate files that aren't kept. Treat them as reference for how a result in `DECISIONS.md` was reached, not as tools to run as-is.

Folders follow the pages: `quad` (Plates 49–55), `gos` (46–47), `unequal` (56–57), `peano` (63–65), `dragon` (66–67), `snow` (68–73), `tsp` (Cesàro order as a travelling-salesman heuristic), and `misc` (Plates 31, 32 and 42–45, the Brownian page, and browser tests).
